
# GitHub Sync Project

Goal:

Allow JupyterLite to save notebooks directly to GitHub.

Requirements:

- Only repository owner can save
- Public users can read and run notebooks
- Public users cannot modify the repository
- Public users may fork the repository
- GitHub remains the source of truth

Status:

- [x] JupyterLite deployed
- [x] GitHub Pages working
- [x] Repository-backed notebooks working
- [ ] GitHub authentication
- [ ] GitHub write-back
- [ ] Save-to-GitHub button
